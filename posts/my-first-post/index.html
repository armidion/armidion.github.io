면접에서 발견한 목표와 경험 사이의 간극을, 앞으로 직접 채워 갈 학습 로드맵으로 정리했습니다.

면접을 통해 얻은 방향성

에퀴닉스 SE 면접을 보며, Cloud Security + Network 엔지니어라는 목표와 지금까지 쌓아 온 경험 사이의 간극을 확인했습니다.

  1. 엔지니어가 되고 싶다고 말했지만, 프로젝트와 공부가 데이터 분석에 치중되어 있었습니다.
  2. 네트워크와 사이버 보안에 대한 기본 체력이 아직 충분하지 않았습니다.
  3. 클라우드를 수박 겉핥기식으로 공부하지 않으려면 네트워크·보안·인프라의 기초부터 연결해야 합니다.

세 가지 축으로 시작하는 로드맵

  1. 네트워크 + 보안에서 클라우드로 확장되는 구조를 이해하기
  2. Terraform으로 반복 가능한 인프라를 코드로 구성하기
  3. OWASP Top 10의 공격 원리를 실습하고, 인프라와 애플리케이션 계층의 방어 방법 연결하기

함께 사용할 학습 도구

  • Udemy — 개념 학습
  • WebGoat — 웹 취약점 원리와 방어 실습
  • KodeKloud — Terraform 실습
